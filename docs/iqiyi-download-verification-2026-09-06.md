# 爱奇艺下载修复实测

验证地址：`https://www.iqiyi.com/v_19rzivlsqk.html`（阿衰 第3季第1集）。

## 原因

浏览器返回的 m3u8 包含 25 个 `data.video.iqiyi.com/videos/vts/` 调度地址。
直接请求分片返回 HTTP 405 / D2102；仅附加播放列表查询参数仍返回 405 / D2001。
播放器实际使用另一条带会话参数的 CDN 地址。旧代码把调度列表直接交给 yt-dlp，
失败分片被逐个跳过，最终得到空文件。

## 修复

- 等待目标 TVID 对应的实际 TS 请求，再结束后台浏览器捕获。
- 仅在 TVID、资源路径、已观察到的分片范围匹配时使用浏览器 CDN 会话。
- 保留所有分片的 start/end/contentlength/sd 参数；拒绝其他资源路径及不支持的播放列表结构。
- 完整的本地临时播放列表交给现有 N_m3u8DL-RE 下载，结束后移除临时列表。
- 普通 HLS 回退禁止跳过缺失分片，限制重试；输出必须非空且包含视频和音频。
- 后台浏览器保持 headless 和 mute-audio，不外放广告音频。

## 验证

- 原始地址与解析出的 CDN 地址对照：原始 405；CDN 第 0、12、24 个分片均为 200 视频数据。
- 整集下载总耗时 18.2 秒，输出 20,582,876 字节。
- FFprobe：H.264 1280×720 视频、AAC 音频，容器时长 190.705488 秒。
- 原播放列表时长合计 191 秒（EXTINF 四舍五入为整数），与输出一致。
- 输出：`downloads/iqiyi-verified/阿衰 第3季第1集-动漫-全集视频在线观看.mp4`。
- unittest：67 项，57 项通过，10 项原有跳过；diff whitespace 检查通过。
- 只对上述链接做了完整网络验证。旧 DASH 输入流程及不同类型播放列表未做本轮实测。
