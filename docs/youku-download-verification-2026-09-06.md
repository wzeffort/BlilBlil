# 优酷下载修复与 CCTV 标签移除

验证地址：`https://v.youku.com/v_show/id_XNjU1NTM0OTc0OA==.html`。

## 修复

- 原模块依赖 `window.__INITIAL_STATE__` 中的旧 streams/segs 结构，当前页面无法提供这些下载数据。
- 改用项目已有 yt-dlp 的 Youku 专用解析器；实际返回 3 种格式，可直接下载正片，不再启动浏览器播放广告。
- 输入先提取唯一视频 ID 并规范化：支持同一链接重复拼接，去掉追踪参数；不同视频混在一起则报错。
- 不跳过缺失分片，设置有限重试和超时；下载后检查非空及视频、音频轨。
- 删除旧的页面猜测与手工分片合并路径。
- 平台发现阶段排除 CCTV 模块，界面不再显示 CCTV 下载标签；保留其源文件。

## 验证结果

- 用重复拼接的链接完成整集下载，总耗时 18.5 秒。
- 文件大小 78,783,132 字节；FFprobe 检查成功。
- H.264 视频 1280×540、AAC 音频，容器时长 554.678277 秒（约 9 分 15 秒）。
- 输出目录：`downloads/youku-verified/`。
- unittest：70 项，60 项通过，10 项原有跳过。
- 创建真实 Tk 窗口检查：优酷标签存在，CCTV 标签不存在。
- 本次网络验证仅覆盖此链接；不同权限或其他类型内容未做完整实测。
